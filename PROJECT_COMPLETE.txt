┌──────────────────────────────────────────────────────────────┐
│  🧮 THE MATH BEHIND IT                                       │
└──────────────────────────────────────────────────────────────┘

PageRank Formula:
  PR(i) = (1-d)/N + d * Σ(PR(j)/L(j))

Where:
  • d = 0.85 (damping factor)
  • N = number of nodes
  • PR(j) = PageRank of nodes pointing to i
  • L(j) = outgoing links from node j

Sample Graph (A→B→C→A, D→C):
  Expected results with d=0.85:
  • C: 0.35 (highest - gets links from B and D)
  • A: 0.28
  • B: 0.22
  • D: 0.15 (lowest - no incoming links)
